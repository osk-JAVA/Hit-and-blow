# ヒットアンドブロー (Hit & Blow)

数字を当てる推理ゲーム「ヒットアンドブロー」のWebブラウザ版です。

## 概要
ランダムに選ばれた重複のない数字の組み合わせを、ヒント（HitとBlowの数）を頼りに当てるゲームです。
ブラウザ上でそのまま動作するため、特別な環境構築なしで手軽に遊ぶことができます。

## 遊び方 / ダウンロード
1. リリースページにアクセスします。https://github.com/osk-JAVA/Hit-and-blow/releases/
2. 最新リリースの `hit_and_blow.html`（または `ヒットアンドブロー.html`）をダウンロードします。
3. ダウンロードしたファイルをお使いのブラウザ（Chrome, Edge, Safariなど）で開くとゲームが始まります。

## ルール
* **Hit（ヒット）**: 数字と位置の両方が合っている数
* **Blow（ブロー）**: 数字は合っているが、位置が異なる数
* ヒントをもとに正しい数字の組み合わせを当てることができればクリアです！
